# Координаты места рождения

`src/data/birthplaceCoordinates.ts` — локальный справочник географических
координат, а не моковые значения персонажа. Загружен 23.11.2026.

- Страны: [Natural Earth, Admin 0 Countries](https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_admin_0_countries.geojson),
  поля ISO_A2_EH и LABEL_X/LABEL_Y. Natural Earth — public domain.
  Используются точки для подписей стран, чтобы метка попадала на основную территорию.
- Дополнение стран: [Google countries.csv](https://developers.google.com/public-data/docs/canonical/countries_csv).
  Используются только двухбуквенные коды и координаты; лицензия страницы CC BY 4.0.
- Города: [GeoNames cities15000](https://download.geonames.org/export/dump/),
  [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
  Выбраны столицы и все города текущего каталога настроек. Сохранены координаты
  и варианты названий; численность населения использована только для разрешения
  совпадающих названий. У отсутствующих в предыдущих источниках стран взята
  координата самого населённого города как приблизительный ориентир страны.

Сначала ищется город внутри его страны, затем точка страны по ISO2. Для неизвестного
кода метка не подставляется. При поиске учитываются регистр, пробелы, пунктуация и ё/е.
Серверные записи и моки используют один компонент `BirthplaceMap`.

Картинка из макета является стилизованной картой. В `src/map/birthplaceMap.ts`
координаты приблизительно совмещены с её силуэтом и преобразованы с учётом
существующей обрезки изображения. Позиция задана процентами и масштабируется
вместе с картой. Если удалённый остров выходит за обрезку, метка остаётся
на ближайшем краю с пояснением. Подсказка явно отличает город от приблизительной
точки страны. Точного адреса и координат места рождения в текущем OpenAPI нет.

Во время игры геокодеры и сторонние API не вызываются. F5 использует сохранённые
countryCode и city; смена имени не влияет на метку. Справочник можно заменить
серверными координатами при расширении контракта.
