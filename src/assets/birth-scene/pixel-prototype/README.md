# Пиксельный набор семьи · рождение

Собственные изображения на целочисленной пиксельной сетке. Выбранная средняя
детализация: простые лица, форма причёсок и двухцветная одежда. Сглаживание
не применяется; у вырезок прозрачность строго 0 или 255.

Фон `background.png`, прежние `mother.png`, `father.png`, `newborn.png`
и первая сцена сохранены без изменений. Набор подключён к семейной карточке
игрового экрана через `FamilyScene.tsx` вместо прежней статичной картинки.

Состав берётся из `simulation.family`, а для старых сессий — из сведений рождения
или сохранённых настроек. Моковая игра использует выбранные настройки и общие
моковые данные. Персонажи выбираются по полу и возрастной группе, поэтому герой
не остаётся младенцем при взрослении. Новорождённые изображены в люльке до 3 лет;
далее используются готовые фигуры 3 / 6 / 10 лет и взрослые с 18 лет.

Серверные ID сохраняют различие людей с одинаковыми именами. Погибшие люди,
друзья и родственники без поддерживаемой связи не попадают в сцену; живые
родители остаются независимо от статуса общения. Компоновка большой семьи
не ограничивается шестью детьми: игровая сцена использует несколько рядов.

## Персональные цвета

В игре доступны 6 оттенков кожи, 6 цветов волос, 8 цветов верха и 6 цветов брюк:
1728 сочетаний для каждого базового взрослого или детского силуэта.
Для младенца меняются кожа, волосы и пелёнка; сама люлька сохраняет свои цвета.

Волосы и одежда вычисляются по ID жизни и устойчивому ID человека; их алгоритм
v1 сохранён. Оттенок кожи использует визуальную модель v2:

- Для человека без известных родителей выбирается один из нескольких оттенков
  с учётом страны. Поддержаны все 36 стран, ISO2, ISO3 и их русские названия.
- Для героя и братьев/сестёр приоритет имеют оттенки известных родителей.
  Между детьми допускаются небольшие отличия.
- Для детей, внуков и следующих поколений используются серверные
  `simulation.adult.npcs[].parentIds`; `character` означает героя.
- При неизвестных родителях или стране работает безопасный общий вариант.
- Первый результат сохраняется в браузере по ID жизни и человека. После F5,
  переезда, взросления, переименования или смерти родных оттенок сохраняется.
  Моковая игра запоминает оттенки на время текущего запуска, а для тех же входных
  данных использует воспроизводимый выбор.

Страна рождения героя берётся из `character.birthplace`, а для NPC при первом
показе может использоваться его `countryIso2`. Уже сохранённый оттенок всегда
имеет приоритет. При недоступном хранилище используются память текущего запуска
и детерминированный расчёт по доступным данным. Backend и снимок сессии не меняются.

Весовые палитры стран — настраиваемые художественные допущения, а не статистика
цвета кожи населения. Сходство с родителями также является условием рисунка;
оно не моделирует генетику и не утверждает биологическое родство. Имена, вера,
язык, каста и другие признаки для выбора оттенка не используются.

`src/game/familyAppearance.ts` задаёт цвета, `src/data/familySpriteLayers.ts`
содержит исходные пиксели, разделённые на цветовые слои. Слои автоматически
собираются из прежних PNG генератором. Прозрачность и контуры сохранены;
перекрашиваются только кожа, волосы и одежда, фон комнаты не затрагивается.
`appearance-sheet@4x.png` показывает примеры палитр; остальные PNG остаются
базовыми исходниками без персональной палитры.

## Сборка из частей

В `render-scene.mjs` функция `familyScene(parentIds, siblingIds)` собирает
примеры на прежнем фоне, разворачивая персонажей к центру. Состав задаётся
массивами ID из каталога. Для этой статической пробной композиции предусмотрено до двух
взрослых и шести старших детей. Младенец добавляется отдельно перед семьёй.

При размещении сохраняй пропорции, используй целые координаты и увеличение
без сглаживания (`image-rendering: pixelated`). Отражение по горизонтали
позволяет ставить фигуру с любой стороны. Внешний размер PNG включает прозрачные
поля; точка привязки в каталоге находится внизу по центру.

Пересоздание набора без дополнительных зависимостей:

```powershell
node src/assets/birth-scene/pixel-prototype/render-scene.mjs
```

Генератор использует встроенную поддержку TypeScript в Node.js для общего модуля палитр.

## Сохранённые версии

- `before-detail/` — первый минималистичный вариант.
- `more-detail/` — второй подробный вариант.
- `before-family-kit/` — исходник, предпросмотр и описание до добавления набора.

Эти копии сохранены для сравнения и восстановления. Общая структура карточки
игры, её подпись и раскрытие описания семьи сохранены. Игровая компоновка
находится в `src/game/familyScene.ts`, компонент и стили — в
`src/components/gamePage/FamilyScene.tsx` и `FamilyScene.module.scss`.

## Файлы подключения к игре

- `src/components/gamePage/GamePage.tsx` — замена прежней картинки и передача
  актуальных сведений о персонаже и семье.
- `src/components/gamePage/FamilyScene.tsx` — отдельный React-компонент сцены.
- `src/components/gamePage/FamilyScene.module.scss` — пиксельное отображение
  с сохранением высоты прежнего изображения, 174 px.
- `src/game/familyScene.ts` — выбор фигур, совместимость источников и компоновка.
- `src/game/familyAppearance.ts` — устойчивые персональные палитры.
- `src/data/appearanceCountryProfiles.ts` — визуальные палитры стран.
- `src/game/familySkin.ts` — выбор оттенков по стране и родительским связям.
- `src/game/useFamilySkinMemory.ts` — сохранение оттенков отдельно для каждой жизни.
- `src/data/familySpriteLayers.ts` — автоматически созданные цветовые слои фигур.
- `tests/familyScene.test.mjs`, `tests/familySceneRendering.test.mjs` — проверки
  составов семьи, возрастов, восстановления и включения сцены в оба режима игры.
- `tests/familyAppearance.test.mjs` — стабильность цветов и сохранение каждого
  пикселя, прозрачности и деталей исходных фигур.
- `tests/familySkin.test.mjs` — страны, семейное сходство, поколения, восстановление
  и недоступное или повреждённое хранилище.
- `family-manifest.json`, `render-scene.mjs`, `README.md` — отметка о подключении
  и описание использования. PNG этого набора при подключении не изменялись.

Ручная проверка: открыть сохранённую жизнь, сравнить фигуры с описанием семьи,
раскрыть описание, обновить страницу и убедиться, что состав тот же. При взрослении
героя с 3, 6, 10 и 18 лет используются следующие имеющиеся возрастные фигуры.
