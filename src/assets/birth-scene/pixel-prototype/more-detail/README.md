# Пиксельная сцена рождения

Собственная пробная сцена рождения на сетке 256 × 144 пикселя. Нарисована кодом;
ассеты и код оригинального сайта не использованы.

Уточнены лица, волосы, одежда и руки взрослых; добавлены детали младенца,
пелёнки и люльки. Размеры вырезок: взрослые — 36 × 68, младенец с люлькой —
44 × 34 пикселя. Фигуры немного увеличены относительно первого примера.
Сглаживание не используется, прозрачность вне силуэтов сохранена.
Фон `background.png` и отрисовка комнаты не изменены.

- `scene.png` — собранная сцена.
- `scene@4x.png` — увеличенный пример 1024 × 576 без сглаживания.
- `background.png` — нейтральная комната.
- `mother.png`, `father.png`, `newborn.png` — отдельные прозрачные PNG.
- `preview.html` — просмотр сцены и вырезок с увеличением без сглаживания.
- `render-scene.mjs` — исходная отрисовка и сохранение PNG без зависимостей.
- `before-detail/` — прежние персонажи, сцены, исходник и описание для сравнения
  и восстановления предыдущего варианта. Эта копия не подключена к приложению.

Пересоздание изображений:

```powershell
node src/assets/birth-scene/pixel-prototype/render-scene.mjs
```

В приложении изображения пока не подключены. Вёрстка игры не менялась.
